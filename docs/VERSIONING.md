# バージョン運用ルール

## バージョン形式

開発中は `X.Y.Z-alpha.N` を使用します。製品版の完成条件を満たすまではα版を継続します。

## ベース番号の変更基準

| 変更内容 | ベース番号 |
| --- | --- |
| 小規模な修正・改善 | `0.1.1` |
| 大きな機能追加・仕様変更 | `0.2.0` |
| 製品版として安定し、完成条件を満たした段階 | `1.0.0` |

変更の規模と成熟度を確認して判断し、機能追加のたびに機械的に番号を上げない。

## α版の連番ルール

- `alpha.N` は更新ごとに1ずつ増やす。
- ベース番号が変わっても連番をリセットしない。
- 例：`0.1.1-alpha.94` → `0.2.0-alpha.95`
- バージョン表記は常に `X.Y.Z-alpha.N` とする。
- 製品版の完成条件を満たすまではα版を継続する。

## 製品版への移行条件

少なくとも、主要機能の実機統合試験、重大不具合の解消、データ移行・復旧の確認、セキュリティ確認、Windows配布物の検証、READMEと変更履歴の整備を完了し、安定運用できると判断できた段階で `1.0.0` へ移行する。CI成功だけを製品版完成の根拠にしない。

## 現在

現在のバージョン：`0.2.0-alpha.46`

`0.2.0` は、コメントビューア・動画ライブラリ・BGM・音声読み上げ・自動化・リモート操作／監査・放送監視など、複数の主要機能群が揃った開発段階を示します。これは安定版を意味せず、実機統合試験と録画機能などの未完了項目が残るため、引き続きα版です。
