# 自動アンケートAPI（β7）

## アプリからの操作

対象番組IDを検証したうえで、Electronの専用永続セッション persist:kananeo-niconico を使って次のAPIを呼び出します。

| 操作 | HTTP | パス |
|---|---|---|
| 開始 | POST | /unama/watch/{lv}/enquete |
| 結果取得・結果表示 | POST | /unama/watch/{lv}/enquete/result |
| 終了 | DELETE | /unama/watch/{lv}/enquete |

開始リクエストのJSONは question と items（選択肢配列）です。結果は data.title と data.items[] の name / rate を読み取ります。

## 安全策

- APIはメインプロセスからのみ実行します。RendererにCookie値は渡しません。
- 対象番組IDは normalizeProgramId で検証します。
- 質問は100文字、選択肢は2個・各50文字までに制限します。
- 投票時間は3〜300秒、結果表示時間は0〜120秒です。
- 結果の選択肢名が設定値と合わない、率が0〜100の範囲外、結果JSONが不正な場合は自動進行を停止します。
- 継続票の最多は再投票、次動画票の最多は次動画への進行、同票・無投票は設定ルールに従います。
- 連続再投票は最大100回で止められ、実行中の停止操作も用意しています。
- 401 / 403 / 404 / 409 / timeout / 応答形式エラーを区別し、成功したと偽装しません。

## API仕様の参照と注意

APIパスと結果JSONの構造は、公開されている以下のコミュニティ実装を参考にしました。

- TORISOUP / UnityNicoliveClient（MIT）。アンケート開始、結果取得、終了のAPIを実装しています。
- 参照した NicoliveApiClient.cs の最終変更は 2024-08-11 です。ニコニコ公式のAPI仕様書ではなく、2026年11月時点の継続動作を保証する資料ではありません。

したがって、HTTPの形式や自動判定ロジックの単体テストが通っても、実際の放送でAPIが成功することは未確認です。実アカウントによる統合試験が必要です。配信主権限のないアカウントではAPIが拒否する場合があります。
