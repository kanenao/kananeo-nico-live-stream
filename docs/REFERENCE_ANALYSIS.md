# 参考アプリ調査メモ

## 配信たん2（ユーザー提供 MSI）
インストーラーを起動せず、MSIのテーブル、設定XML、埋め込みファイルを静的に調べたメモです。

- MSI ProductVersion: 5.7.85
- Broadcast.exe file version: 5.7.8.5
- .NET Framework: 4.8
- 66ファイルを確認
- WebView2、SQLite、WebSocket系、音声ライブラリ、カメラ関連、音声認識関連ライブラリを同梱

### 参考にする機能
- 番組枠取り、次枠取り、自動次枠
- 無料延長、自動延長、配信ツール再接続
- OBS / N Air / XSplitの起動・終了・シーン制御
- コメントビューア、コテハン、184制御、NGワード / NGユーザー
- 音声認識コマンド、テンキー操作、定時通知、自動応答
- ジュークボックス、プレイリスト、音量調整
- 通信状態監視・復帰通知
- GPS・地図など車載配信向け機能（コアと分離した拡張候補）

この調査は静的なファイル構造確認であり、アプリの起動やAPI通信を試したものではありません。ソースコード、画像、実行ファイルのコピーはしていません。
