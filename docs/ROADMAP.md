# β版ロードマップ

## β2：UI・ローカル設定
- 独自ダークUI、機能別ページ
- 動画リクエストキュー / アンケート設定
- 次枠・延長設定 / 外部配信ツール設定
- NGリスト / BGMプレイリスト / JSONバックアップ

## β3：ニコ生接続基盤
- 専用ログインセッション
- 放送ID・URL検証
- 番組ページ取得・埋め込みデータ解析
- Cookieを表示・ログ出力しない認証設計

## β4：NDGRコメント受信（今回）
- ニコ生専用セッションによるログイン
- 視聴用WebSocket・NDGRストリーム接続
- Protobuf HTTPストリーム受信をnicomgetに委譲
- コメント / 放送者コメント / ギフト / エモーション / 通知を分類
- 接続状態と自動再接続
- 検索 / 種別フィルター / コピー / CSV保存
- Cookieと生データをRendererへ渡さない
- 接続先allowlist、単体テスト

## β5：コメント保存・接続安定化（今回）
- 受信コメント全件のJSONL自動保存
- 自動保存ON/OFFと保存先フォルダのUI
- NDGRストリーム異常時の監視付き再接続
- 表示上限1,000件と全件アーカイブを分離

## β6：動画リクエスト・プレイヤー
- コメントからのリクエスト受付、重複制御
- 再生キュー・ストック・自動再生
- 再生位置と動画時間の同期
- 終了後の次動画遷移、黒画面対策

## β7：自動アンケート
- 現行APIに基づく投票作成・結果取得方法の確認
- 継続票最多なら再投票
- 「次の動画へ」が最多なら次動画へ
- 同票・無投票時の再投票設定
- 投票時間と結果表示時間の変更

## β8：配信運用自動化
- 番組作成 / 次枠 / 自動次枠
- 無料延長条件の確認
- OBS / N Air / XSplitの起動・シーン操作

## β9：音声・配布
- コメント読み上げ・音声コマンド・自動応答
- ジュークボックス・音量制御
- ログ、バックアップ、更新通知
- Windowsインストーラー / ポータブル版

実通信・配信操作は、利用可能な接続仕様と利用規約を確認してから実装します。未検証の操作を成功したように見せません。
