# β版ロードマップ

## β2：UI・ローカル設定
- 独自ダークUI、機能別ページ
- 動画リクエストキュー
- 自動アンケート設定
- 次枠・延長設定
- OBS / N Air / XSplitの実行パス
- NGリスト、BGMプレイリスト、設定JSONバックアップ

## β3：ニコ生接続基盤（今回）
- 専用の永続ログインセッション
- ニコニコ公式ログインページを開く
- Cookie値を表示・保存・ログ出力しないセッション状態確認
- 放送ID・URL検証
- 番組ページ取得、埋め込みデータ解析
- ページ仕様変更や認証・HTTPエラーの明示

## β4：コメント受信
- 現行NDGRメッセージサーバーの仕様調査・実装
- HTTPストリーミング / Protobufのデコード
- コメント、運営通知、広告等のメッセージ分類
- 切断・再接続・二重受信防止
- コメント検索・コピー・保存

## β5：動画リクエスト・プレイヤー
- コメントからの受付、重複制御
- 再生キュー・ストック・自動再生
- 再生位置と動画時間の同期
- 終了後の次動画遷移、黒画面対策

## β6：自動アンケート
- 投票結果の取得方法を現行仕様で確認
- 継続票最多なら再投票
- 「次の動画へ」が最多なら次動画へ
- 同票・無投票時の再投票設定
- 投票待ち時間と結果表示時間の変更

## β7：配信運用自動化
- 番組作成 / 次枠 / 自動次枠
- 無料延長条件の確認
- OBS / N Air / XSplitの起動・シーン操作

## β8：音声・配布
- コメント読み上げ・音声コマンド・自動応答
- ジュークボックス・音量制御
- ログ、バックアップ、更新通知
- Windowsインストーラー / ポータブル版

すべての通信・配信操作は、利用規約と接続仕様を確認してから実装します。未検証の操作は成功したように見せません。
