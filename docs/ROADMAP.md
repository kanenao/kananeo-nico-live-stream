# β版ロードマップ

## β2：UI・ローカル設定
- 独自ダークUI、機能別ページ
- 動画リクエストキュー
- 自動アンケート設定
- 次枠・延長設定
- OBS / N Air / XSplitの実行パス
- NGリスト、BGMプレイリスト
- 設定JSONの書き出し

## β3：ニコ生接続基盤
- 利用可能な認証方式・API仕様の確認
- セッションをログに出さない設計
- 放送自動検出 / 手動ID接続
- 接続・切断・再接続・権限確認

## β4：コメント管理
- コメント受信、検索、コピー、保存
- 来場者数・コメント数・残り時間
- NGワード / NGユーザー / コテハン

## β5：動画リクエスト・プレイヤー
- コメントからの受付、重複制御
- 再生キュー・ストック・自動再生
- 再生位置と動画時間の同期
- 終了後の次動画遷移、黒画面対策

## β6：自動アンケート
- 結果APIから選択肢名・投票率を直接取得
- 継続票最多なら再投票
- 「次の動画へ」が最多なら次動画へ
- 同票・無投票時の再投票設定
- 投票待ち時間と結果表示時間の変更

## β7：配信運用自動化
- 番組作成 / 次枠 / 自動次枠
- 無料延長条件の確認
- OBS / N Air / XSplitの起動・シーン操作

## β8：音声・配布
- コメント読み上げ・音声コマンド・自動応答
- ジュークボックス・音量制御
- ログ、バックアップ、更新通知
- Windowsインストーラー / ポータブル版

すべての通信・配信操作は、利用規約と接続仕様を確認してから実装します。確認できない操作を成功したように見せません。
