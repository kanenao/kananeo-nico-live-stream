# kananeo nico live stream

総合ニコ生管理デスクトップアプリの独自プロジェクトです。

## 現在のバージョン

**0.1.0-beta.3** — ニコ生専用ログインセッションと番組ページ確認を追加しました。

## β3で追加した機能

- ニコニコ公式ログイン画面を専用の永続セッションで開く
- ログインCookieの存在のみを確認（値は表示・ログ出力しない）
- このアプリ専用セッションのログアウト
- 放送ID / ニコ生番組URLの検証
- 番組ページの取得と `embedded-data` の解析
- 視聴用WebSocket API情報の有無を安全に判定
- タイムアウト / ログイン要求 / 404 / 403 / ページ仕様変更の判別
- `npm test` の単体テスト

## β2から引き継いだローカル機能

- 動画リクエストキューの追加・順番変更・削除
- 自動アンケートの待ち時間・結果表示時間・判定ルールの保存
- 次枠・自動延長の設定値保存
- OBS / N Air / XSplit の実行パス設定
- BGMプレイリスト、NGワード、NGユーザー
- 設定JSONの書き出し・読み込み

## 起動方法

1. Node.js 20以降をインストール
2. プロジェクトルートで `npm install`
3. `npm test`
4. `npm start`

## 重要：β3でも未実装の機能

コメント用NDGRメッセージサーバー接続、コメント受信・送信、動画再生、アンケート作成・結果API、番組作成、次枠、無料延長、OBS等の外部操作はまだ未実装です。番組ページ確認に成功しても、コメント受信接続が成功したことを意味しません。

## 認証とプライバシー

メールアドレスとパスワードをアプリで受け取る旧ログイン方式は実装しません。ニコニコ公式Webログインを専用Electronセッションで開きます。普段のChrome / EdgeのCookieを読み取りません。Cookie値やトークンはGitHubに登録しません。
