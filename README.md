# kananeo nico live stream

総合ニコ生管理デスクトップアプリの独自プロジェクトです。

## 現在のバージョン

**0.1.0-beta.2**

配信たん2の機能調査を反映したUI・設定プロトタイプです。Electron製のWindowsデスクトップアプリとして開発しています。

## 主なモジュール

- ダッシュボード
- 放送・枠管理
- コメントビューア
- 動画リクエスト（ローカルキュー）
- 自動アンケート設定
- プレイヤー・BGM
- 自動枠取り・延長設定
- OBS / N Air / XSplit 設定
- 音声・自動応答
- ユーザー・NG管理
- 履歴・バックアップ
- アプリ設定

## β2で使える機能

- 各画面の移動
- 動画リクエストキューの追加・順番変更・削除
- 自動アンケートの待ち時間・結果表示時間・判定ルールの保存
- 次枠・自動延長の設定値保存
- 外部配信ツールの実行パス保存
- BGM曲名リストの保存
- NGワード・NGユーザー登録
- 設定のJSON書き出し・読み込み

## 起動方法

1. Node.js 20以降をインストール
2. プロジェクトルートで `npm install`
3. `npm start`

## 重要：未実装機能

このバージョンではニコ生ログイン、放送自動検出・接続、コメント受信、動画/BGM実再生、アンケート作成・結果API取得、番組作成・次枠取得、無料延長API操作、OBS等の外部プロセス操作はまだ実装していません。画面上の準備中表示を実機能と誤認しないようにしてください。

## 参考にしたプロジェクト

- 配信たん2：運用自動化、次枠・延長、外部配信ツール、音声、通知、ジュークボックス等の機能設計を参考
- NicoLiveHelper Standalone：ニコ生の接続・コメント・動画リクエスト管理の考え方を参考

既存のソースコード、画像、実行ファイルは複製せず、機能要件のみを参考に独自実装します。

## セキュリティ・開発方針

- パスワードやCookieを通常ログに出さない
- 利用可能なログイン/API方式と利用規約を確認してから通信機能を実装
- 自動延長や番組操作の前に放送状態・権限を確認
- 外部ツールはユーザーが明示登録した実行ファイルのみを対象とする
- 接続処理はサービス層として分離し、API変更に備える
