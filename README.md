## α100：地震情報の運営コメント自動通知

- **運営コメントで地震情報を通知**：P2P地震情報のJSON API v2（コード551）経由で、気象庁が発表した地震情報を取得し、ログイン中の自分のニコ生放送へ運営コメントとして自動送信できます。
- **初期OFF**：放送者が「地震情報を運営コメントへ自動投稿」をONにしたときのみ動作します。設定画面は「放送・枠管理」と「24時間放送監視」にあります。アプリを閉じている間は監視しません。
- **震度条件と間隔**：初期は最大震度3以上、確認間隔30秒。最低震度は1〜7（5弱・5強・6弱・6強に対応）、取得間隔は30秒・60秒・120秒・300秒から選択できます。手動の「最新情報を確認」は投稿を行いません。
- **投稿内容**：例として「【地震情報】最大震度4／震源:宮城県沖／M5.2／00:57頃／出典:気象庁/P2P地震情報」の形式で、地震の規模・震源・時刻・出典を最大80文字のニコ生運営コメントにまとめます。内容は実際の受信情報から生成し、数値を推測しません。
- **重複・連投防止**：有効化・アプリ起動時には直近の履歴を同期するだけで過去の地震を投稿しません。報告ID・地震発生時刻で重複を防ぎ、10分より古い報告は送信しません。地震通知同士は3分以上、通常の自動運営コメントとは5秒以上の間隔を確保します。
- **送信先の安全確認**：投稿時に自分の放送履歴と放送状態を再取得し、ログイン中のアカウント自身が放送中の番組以外への自動送信を拒否します。情報IDは取得済みのデータからのみ選択され、任意の警告文を登録する仕様ではありません。
- **履歴・失敗理由**：最新取得情報・状態・次回確認時刻、投稿成功・失敗の履歴を画面に表示し、履歴だけを削除できます。
- **重要**：**この機能は地震情報であり、緊急地震速報（警報）ではありません。** 情報が遅れたり届かないことがあります。避難や身の安全の判断には気象庁などの公式防災情報を参照してください。実際のニコ生の投稿権限・仕様は実配信での確認が必要です。

- **不具合修正**：引用動画の残り尺がアンケートの待機・投票・結果表示時間より短いと、アンケート省略後に次動画へ移らず停止する問題を修正しました。

- **留意点**：ニコ生の引用APIには再生終了イベントや正確な再生位置がないため、完走はアプリが確認した開始時刻と動画の長さからの予定時刻到達を意味します。実配信での最終検証は未実施です。

## α90：自動更新HTTP 404の復旧経路を追加

- **原因調査**：GitHubの公開α版に`alpha.yml`とSetup版が存在していても、Electron自動更新でHTTP 404が続くケースへの対応を強化しました。

## バージョン運用ルール

本プロジェクトは製品版の完成条件を満たすまでα版を継続します。バージョンは `X.Y.Z-alpha.N` 形式で管理します。

- 小規模な修正・改善：ベース番号を `0.1.1` にする
- 大きな機能追加・仕様変更：ベース番号を `0.2.0` にする
- 製品版として十分に安定し、リリース条件を満たした段階：`1.0.0` にする
- `alpha.N` は更新ごとに1ずつ増やし、ベース番号が変わってもリセットしない
- 例：`0.1.1-alpha.94` → `0.2.0-alpha.95`
- 製品版の完成条件を満たすまでは、`beta` や正式版へ移行せずα版を継続する

詳細は [docs/VERSIONING.md](docs/VERSIONING.md) を参照してください。

## α5のコメント保存

- 自動保存は接続画面でON/OFFできます（初期状態はON）。

## α6〜α16の制限事項

- プレビューはニコニコ公式の動画ページを専用ウィンドウで開きます。これとは別に、α11から引用再生APIで番組へ動画を送れるようになりました。
- 終了検知はページ内のHTML5 `video` 要素を監視する方式です。ニコニコ側のページ構造変更、広告・読み込み状態、プレイヤー内部の実装によっては検知できない場合があります。その場合はアプリの「次の動画へ」を使用してください。
- 対応対象はHTTPSのニコニコ動画 watch URL / 動画ID（`sm` / `nm` / `so`）です。YouTube、外部サイト、チャンネルURL、ローカル動画ファイルは未対応です。マイリスト・あとで見る・シリーズは動画ライブラリへの一覧取り込みに対応しています。
- コメントからの明示コマンドによる自動リクエスト受付は実装済みです。ニコ生の運営コメント自動返信はα15で実装しました（初期OFF）。通常視聴者としてのコメント送信、番組作成、次枠、実際の延長、OBS等の外部操作は未実装です。
- α6のプレビュー終了検知、α7のアンケートAPI、α8の統計API、α10の延長方法照会、α11の引用再生API、α12の自動次動画、α15の運営コメント送信、α16のマイリスト／あとで見る／シリーズ取得は実アカウントでの統合試験が必要です。単体テスト成功は、実配信での動作保証ではありません。

## α7の自動アンケートの使い方

1. 「放送・枠管理」でニコニコ公式ログインを行い、対象の放送IDを確認します。
2. 「自動アンケート」で質問、2つの選択肢、投票時間、結果表示時間を設定して保存します。
3. 「自動アンケート開始」を押すと投票開始 → 結果取得 → 結果表示 → アンケート終了の順に実行します。
4. 継続側が最多なら再投票し、次動画側が最多なら現在の動画を完了扱いにして次の待機動画を開きます。
5. 実行中は「停止」で中断できます。最大100回で安全停止します。

ニコニコ側の放送主権限が必要です。401 / 403 / 404 / 409 等のAPIエラーが返された場合は処理を停止します。投票結果のAPI形式が設定した選択肢と一致しない場合も自動進行しません。

## 動画ライブラリの使い方（α18）

1. アプリ左側の「動画ライブラリ」を開きます。
2. ニコニコ動画IDまたはwatch URLを入力して、個別に登録できます。
3. 「一括取り込み」で、取り込み元（あとで見る／マイリスト／シリーズ）を選びます。マイリスト・シリーズの場合はIDまたはURLを入力します。
4. あとで見る・マイリスト・シリーズの取得では、最初に「放送・枠管理」でニコニコ公式ログインを行ってください。「一覧を表示して選択」で内容を確認し、取り込みたい動画だけチェックして保存できます。
5. 動画IDやURLを改行区切りで貼り付ける方法、JSONバックアップの読み込みにも対応しています。
6. 登録済み動画は検索・並び替えができ、プレビュー再生・引用再生は履歴に記録されます。

ライブラリと再生履歴はPC内のElectronユーザーデータフォルダーに保存されます。JSONを書き出して別PCへ移すこともできます。あとで見る・マイリスト・シリーズは最大1,000件までの取り込みです。マイリストは最大2ページ（500件×2）、シリーズはAPI応答の総件数を利用して最大1,000件を要求し、総件数が取得できない場合は最大500件です。APIはニコニコの非公開Web APIに依存するため、実アカウントで取得できるかは環境・権限・API側の変更に左右されます。

## 重要：未実装・未検証の機能

α11の引用再生はGET / POST / PATCH / DELETEのAPI接続を実装済みです。α12では登録済み動画時間から次動画への予定時刻を計算し、切替直前に引用再生状態を照会します。これは実際の動画再生位置・終了イベントを受信する方式ではなく、動画時間に基づくタイマー方式です。動画時間が不明な場合は自動切替しません。

コメント受信はNDGRメッセージストリームを使用します。通常視聴者としてのコメント送信、番組作成、次枠、実際の延長、OBS等の外部操作は未実装です。α15の運営コメント自動返信は初期OFFで、配信主権限が必要です。コメント接続の成功は配信主権限を意味しません。

α6のプレイヤー、α7のアンケートAPI、α8の統計APIは、実アカウント・実放送を使った統合試験はまだ実施していません。自動再接続とローカル保存は単体テスト・コード確認を追加していますが、配信をつないだ長時間試験は別途必要です。接続仕様の変更によって動作しない場合があります。

## 認証とプライバシー

メールアドレス・パスワードをアプリが直接送る旧方式は実装しません。ニコニコ公式Webログインを専用Electronセッションで開きます。普段使いのChrome / EdgeのCookieを読み取りません。セッションから読み取ったCookieはメインプロセス内だけで利用し、画面・ログ・CSV・GitHubへ出力しません。

## リモート接続監査ログ（α33）

リモートコントローラーの認証失敗、接続拒否、レート制限、ペアリング、操作結果を `remote-control-audit.jsonl` に記録します。時刻・イベント種別・接続元IP・HTTPメソッド・APIパス・許可された操作名のみを保存し、Bearerトークン、ペアリングコード、リクエスト本文、コメント内容は記録しません。ログはElectronのユーザーデータフォルダーに保存されます。


## リモート監査ログビューア（α34）

サイドメニューの「監査ログ」で接続拒否・認証失敗・レート制限・ペアリング・操作結果を確認できます。イベント種別・期間・キーワードで絞り込み、CSVへ出力できます。アプリ起動時にJSONL保存履歴を復元し、直近500件を表示します。ログファイルは2MBで1世代ローテーションし、現在分と直前分を保持します。Bearerトークン、ペアリングコード、リクエスト本文、コメント本文は出力しません。
