# kananeo nico live stream

総合ニコ生管理デスクトップアプリの独自プロジェクトです。

## 現在のバージョン

**0.1.0-beta.6** — ニコニコ動画リクエストキューと公式動画プレイヤー連携を追加しました。

## β6で追加した機能

- `sm` / `nm` / `so` の動画IDとHTTPS watch URLの検証
- 動画リクエストの登録、重複防止、並べ替え、削除
- 再生中 / 待機中 / 再生済み / スキップの状態管理
- アプリ専用ニコニコログインセッションを共有する公式動画プレイヤーウィンドウ
- HTML5動画の再生状態、再生位置、動画時間を約1秒間隔で監視
- 動画終了を検知できた場合の自動次動画切替
- 手動の次動画切替、自動切替ON/OFF
- URL検証・次動画選択・コメントコマンド解析の単体テスト
- コメントからのリクエスト自動受付（初期OFF。`リクエスト sm12345678` / `リク https://www.nicovideo.jp/watch/sm...` / `request sm...`）
- 通常コメントのみ対象。過去コメント、NGユーザー、NGワードを除外し、重複と200件上限をチェック

## β4 / β5で追加した機能

- ニコニコ公式ログイン専用セッションを利用したコメント接続
- 現行NDGRコメントストリームを利用したリアルタイム受信
- 過去コメント（バックログ）の取得ON/OFF
- コメント、放送者コメント、ギフト、エモーション、通知の受信
- 接続状態の表示とprovider側の自動再接続
- コメント検索、種別フィルター、コピー、CSV保存
- 表示件数の上限（最大1,000件）
- 受信コメント全件のJSONL自動保存（ON/OFF可能）
- NDGRストリーム異常時の監視付き再接続
- コメント保存先フォルダをUIから開く
- Cookie値、WebSocket URL、raw Protobufを画面やログへ出さない
- NDGR接続先のallowlist検証と単体テスト

## β2 / β3から引き継いだ機能

- 動画リクエストキューの追加・順番変更・削除
- 自動アンケートの待ち時間・結果表示時間・判定ルールの保存
- 次枠・自動延長の設定値保存
- OBS / N Air / XSplit の実行パス設定
- BGMプレイリスト、NGワード、NGユーザー
- 設定JSONの書き出し・読み込み
- ニコニコ公式ログイン画面を専用セッションで開く
- 放送ID / URLの検証、番組ページ情報確認

## 起動方法

1. Node.js 20以降をインストール
2. プロジェクトルートで `npm install`
3. `npm test`
4. `npm start`

## コメント受信手順

1. 「放送・枠管理」からニコニコ公式ログインを行います。
2. 「コメントビューア」で放送IDまたは番組URLを入力します。
3. 必要に応じて「過去コメントも取得」を有効にします。
4. 「コメント受信を開始」を押します。
5. 必要に応じて「コメントを自動保存する」をONにして受信を開始します。
6. 検索・種別フィルター・コピー・CSV保存を使えます。全受信コメントはJSONLファイルにも保存できます。

## β5のコメント保存

- 自動保存は接続画面でON/OFFできます（初期状態はON）。
- 保存先はElectronのユーザーデータフォルダー内の `comment-recordings` です。「保存先フォルダ」から開けます。
- 1放送ごとにJSONLファイルを作成し、一般コメント・放送者コメント・ギフト・通知などの受信イベントを追記します。
- ファイルには表示用に整形した項目だけを保存します。Cookie、WebSocket URL、raw Protobufは保存しません。
- CSV保存は画面に保持されている最大1,000件が対象です。長時間配信の全件ログはJSONLを利用してください。

## β6の制限事項

- 現在のプレイヤーはニコニコ公式の動画ページを専用ウィンドウで開きます。再生・一時停止・画質などは公式プレイヤー側で操作してください。
- 終了検知はページ内のHTML5 `video` 要素を監視する方式です。ニコニコ側のページ構造変更、広告・読み込み状態、プレイヤー内部の実装によっては検知できない場合があります。その場合はアプリの「次の動画へ」を使用してください。
- 対応対象はHTTPSのニコニコ動画 watch URL / 動画ID（`sm` / `nm` / `so`）です。YouTube、外部サイト、マイリスト、チャンネルURL、ローカル動画ファイルは未対応です。
- コメント本文からの自動リクエスト抽出、ニコ生へのコメント送信・運営コメント送信、アンケートAPI、番組作成、次枠、無料延長、OBS等の外部操作は未実装です。
- β6の動画終了検知・連続再生は実アカウント・実動画で未検証です。GitHub Actionsのテスト成功は、実配信での動作保証ではありません。

## 重要：β5から引き継いだ未実装の機能

コメント受信は視聴用WebSocketとNDGRメッセージストリームを使用しますが、コメント送信・運営コメント送信、アンケート作成・結果API、番組作成、次枠、無料延長、OBS等の外部操作は未実装です。コメント接続の成功は配信主権限を意味しません。

本版では実アカウント・実放送を使った統合試験はまだ実施していません。自動再接続とローカル保存は単体テスト・コード確認を追加していますが、配信をつないだ長時間試験は別途必要です。接続仕様の変更によって動作しない場合があります。

## 認証とプライバシー

メールアドレス・パスワードをアプリが直接送る旧方式は実装しません。ニコニコ公式Webログインを専用Electronセッションで開きます。普段使いのChrome / EdgeのCookieを読み取りません。セッションから読み取ったCookieはメインプロセス内だけで利用し、画面・ログ・CSV・GitHubへ出力しません。
