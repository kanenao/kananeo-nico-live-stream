# kananeo nico live stream

総合ニコ生管理デスクトップアプリの独自プロジェクトです。

## 現在のバージョン

**0.1.0-beta.30** — NCV風コメント欄の表示設定をカスタマイズできるようにしました。

## β30で追加した機能

- コメント文字サイズを8〜18pxで調整
- コメント番号・時刻・投稿者・ユーザーID・本文・種別の各列を個別に表示／非表示
- ↑／↓操作でコメント列の並び順を変更
- 通常コメント・放送者コメント・ギフト・エモーション・通知の文字色を個別設定
- 表示設定をPC内へ保存し、アプリ再起動後も復元
- コメント本文列を常時表示し、保存データの文字サイズ・色コード・列順を検証
- 表示設定の正規化モジュールと単体テストを追加

設定は「放送・枠管理」→「コメント表示をカスタマイズ」から変更できます。チェック項目や色を選択し、「表示設定を保存」を押してください。列順は↑／↓で入れ替えられます。

## β29で追加した機能

- 「放送・枠管理」に放送映像（左）とコメント一覧（右）の横並び表示を追加
- ニコニコ公式の視聴ページをアプリ内の映像領域へ表示（既存の専用ログインセッションを共有）
- 放送画面の表示・終了、コメント受信の開始・切断を同じパネルに集約
- NCV風のコメント表（番号／時刻／投稿者／ユーザーID／本文／種別）を追加
- コメント本文・投稿者名・ユーザーIDの検索、コメント種別フィルター、投稿者別絞り込み
- コメント番号から既読位置を記録し、ダブルクリックで解除
- コメントの自動スクロールは一覧の最下部にいる場合だけ実行
- コメント行の右クリックメニューから本文／IDコピー、投稿者の絞り込み、NGユーザー／NGワード追加、コテハン登録
- 画面切替時は映像ビューを隠し、放送管理ページに戻ると再表示
- 映像ビューの表示領域を画面サイズ・スクロール位置に合わせて更新し、画面外の表示領域をクリップ
- 表示領域の検証・クリッピングを独立モジュール化し、単体テストを追加

**注意：映像はニコニコ公式の視聴ページを埋め込んで表示します。視聴権限・ログイン状態・ニコニコ側のページ仕様によっては映像が出ない場合があります。コメントはNDGR受信結果を表示します。NCV本体の機能を複製するものではありません。**

## β28で追加した機能

- 番組管理画面を開く前に、対象放送IDを使って公式番組ページを再確認
- 番組名・現在の状態（放送中／予約／終了など）を表示してから管理画面を開く
- 確認済み情報の有効期限を90秒に制限し、期限切れ・対象ID変更時は再確認を必須化
- 既存の「番組ページを確認」と管理対象IDを同期し、確認した番組をそのまま管理へ引き継ぐ
- 番組状態の表示・確認期限・ID一致条件を独立モジュール化し、単体テストを追加

**注意：β28も公式画面を操作する方式です。アプリから直接番組を作成・終了するAPIは組み込んでいません。放送終了は公式管理画面上で利用者が確認して実行します。**

## β26で追加した機能

- 認証処理・失効・権限判定・接続先制限・レート制限の単体テスト

**注意：β26は認証ロジックの基盤のみです。HTTP／WebSocketサーバー、外部端末からの接続、リモート操作UIはまだ有効化していません。**

## β24で追加した機能

- BGM画面から複数の音源ファイルを選択してアプリ専用フォルダーへコピー
- BGMライブラリをローカルJSONで保存し、アプリ再起動後もプレイリストを維持
- 再生・一時停止・停止・前の曲・次の曲に対応

BGM音声はPCから出力するローカル再生です。ニコ生へ直接送信するものではなく、配信に含める場合はOBS等でデスクトップ音声を取り込んでください。実際に再生できる音声形式はWindows／Chromium環境に依存します。

## Windows版のビルド

Windows環境で以下を実行すると、`dist` フォルダーにNSISインストーラーとポータブル版を生成します。

```bash
npm install
npm test
npm run dist:win
```

GitHubのActionsタブから「Windows Build」を手動実行するか、`v*` タグをpushするとWindows x64ビルドを実行します。生成EXEはワークフローのArtifactsから取得できます（保存期間14日）。現時点では署名証明書を設定していないため、Windows SmartScreenの警告が出る可能性があります。

## コメント受信手順

1. 「放送・枠管理」からニコニコ公式ログインを行います。
2. 「コメントビューア」で放送IDまたは番組URLを入力します。
3. 必要に応じて「過去コメントも取得」を有効にします。
4. 「コメント受信を開始」を押します。
5. 必要に応じて「コメントを自動保存する」をONにして受信を開始します。
6. 検索・種別フィルター・コピー・CSV保存を使えます。全受信コメントはJSONLファイルにも保存できます。

## β5のコメント保存

- 自動保存は接続画面でON/OFFできます（初期状態はON）。
- 保存先はElectronのユーザーデータフォルダー内の `comment-recordings` です。「保存先フォルダ」から開けます。
- 1放送ごとにJSONLファイルを作成し、一般コメント・放送者コメント・ギフト・通知などの受信イベントを追記します。
- ファイルには表示用に整形した項目だけを保存します。Cookie、WebSocket URL、raw Protobufは保存しません。
- CSV保存は画面に保持されている最大1,000件が対象です。長時間配信の全件ログはJSONLを利用してください。

## β6〜β16の制限事項

- プレビューはニコニコ公式の動画ページを専用ウィンドウで開きます。これとは別に、β11から引用再生APIで番組へ動画を送れるようになりました。
- 終了検知はページ内のHTML5 `video` 要素を監視する方式です。ニコニコ側のページ構造変更、広告・読み込み状態、プレイヤー内部の実装によっては検知できない場合があります。その場合はアプリの「次の動画へ」を使用してください。
- 対応対象はHTTPSのニコニコ動画 watch URL / 動画ID（`sm` / `nm` / `so`）です。YouTube、外部サイト、チャンネルURL、ローカル動画ファイルは未対応です。マイリスト・あとで見る・シリーズは動画ライブラリへの一覧取り込みに対応しています。
- コメントからの明示コマンドによる自動リクエスト受付は実装済みです。ニコ生の運営コメント自動返信はβ15で実装しました（初期OFF）。通常視聴者としてのコメント送信、番組作成、次枠、実際の延長、OBS等の外部操作は未実装です。
- β6のプレビュー終了検知、β7のアンケートAPI、β8の統計API、β10の延長方法照会、β11の引用再生API、β12の自動次動画、β15の運営コメント送信、β16のマイリスト／あとで見る／シリーズ取得は実アカウントでの統合試験が必要です。単体テスト成功は、実配信での動作保証ではありません。

## β7の自動アンケートの使い方

1. 「放送・枠管理」でニコニコ公式ログインを行い、対象の放送IDを確認します。
2. 「自動アンケート」で質問、2つの選択肢、投票時間、結果表示時間を設定して保存します。
3. 「自動アンケート開始」を押すと投票開始 → 結果取得 → 結果表示 → アンケート終了の順に実行します。
4. 継続側が最多なら再投票し、次動画側が最多なら現在の動画を完了扱いにして次の待機動画を開きます。
5. 実行中は「停止」で中断できます。最大100回で安全停止します。

ニコニコ側の放送主権限が必要です。401 / 403 / 404 / 409 等のAPIエラーが返された場合は処理を停止します。投票結果のAPI形式が設定した選択肢と一致しない場合も自動進行しません。

## 動画ライブラリの使い方（β18）

1. アプリ左側の「動画ライブラリ」を開きます。
2. ニコニコ動画IDまたはwatch URLを入力して、個別に登録できます。
3. 「一括取り込み」で、取り込み元（あとで見る／マイリスト／シリーズ）を選びます。マイリスト・シリーズの場合はIDまたはURLを入力します。
4. あとで見る・マイリスト・シリーズの取得では、最初に「放送・枠管理」でニコニコ公式ログインを行ってください。「一覧を表示して選択」で内容を確認し、取り込みたい動画だけチェックして保存できます。
5. 動画IDやURLを改行区切りで貼り付ける方法、JSONバックアップの読み込みにも対応しています。
6. 登録済み動画は検索・並び替えができ、プレビュー再生・引用再生は履歴に記録されます。

ライブラリと再生履歴はPC内のElectronユーザーデータフォルダーに保存されます。JSONを書き出して別PCへ移すこともできます。あとで見る・マイリスト・シリーズは最大1,000件までの取り込みです。マイリストは最大2ページ（500件×2）、シリーズはAPI応答の総件数を利用して最大1,000件を要求し、総件数が取得できない場合は最大500件です。APIはニコニコの非公開Web APIに依存するため、実アカウントで取得できるかは環境・権限・API側の変更に左右されます。

## 重要：未実装・未検証の機能

β11の引用再生はGET / POST / PATCH / DELETEのAPI接続を実装済みです。β12では登録済み動画時間から次動画への予定時刻を計算し、切替直前に引用再生状態を照会します。これは実際の動画再生位置・終了イベントを受信する方式ではなく、動画時間に基づくタイマー方式です。動画時間が不明な場合は自動切替しません。

コメント受信はNDGRメッセージストリームを使用します。通常視聴者としてのコメント送信、番組作成、次枠、実際の延長、OBS等の外部操作は未実装です。β15の運営コメント自動返信は初期OFFで、配信主権限が必要です。コメント接続の成功は配信主権限を意味しません。

β6のプレイヤー、β7のアンケートAPI、β8の統計APIは、実アカウント・実放送を使った統合試験はまだ実施していません。自動再接続とローカル保存は単体テスト・コード確認を追加していますが、配信をつないだ長時間試験は別途必要です。接続仕様の変更によって動作しない場合があります。

## 認証とプライバシー

メールアドレス・パスワードをアプリが直接送る旧方式は実装しません。ニコニコ公式Webログインを専用Electronセッションで開きます。普段使いのChrome / EdgeのCookieを読み取りません。セッションから読み取ったCookieはメインプロセス内だけで利用し、画面・ログ・CSV・GitHubへ出力しません。
